Entry for the [One Line, One Laugh](https://make.fun/bounty/u-4z4ghtbwm1fn7mibrqum4bxgfghhgqzriyhd8v3-one-line-0be61e5a) bounty on make.fun ($2 prize pool, deadline 26 Nov 2026 08:45 WIB).

## The line

> My screen-time report just filed for custody of my attention, and honestly, it has a strong case.

## How it works

`main.py` is a small deterministic Python program (no network, no randomness).
It writes the single line above to `/output/entry.txt` (97 characters, UTF-8),
which the make.fun judge compares pairwise against the other entries.

Run it locally:

```sh
python3 main.py
cat /output/entry.txt
```
